# SCHOOL ACCESSORIES MART – FEATURES

## Overview

School Accessories Mart is a scalable backend platform for managing:

- Schools
- Uniform catalogs
- Parent registrations
- Cart management
- Order processing
- Delivery tracking

---

## Core Features

### Authentication
- Parent registration/login
- Admin login
- JWT authentication
- Role-based authorization

### School Management
- Create school
- Update school
- Soft delete school
- List schools

### Uniform Management
- Uniform categories
- Sizes and pricing
- School-wise uniform listing
- Inventory-ready architecture

### Cart Management
- Add item to cart
- Update quantity
- Remove item
- View active cart

### Order Management
- Create order from cart
- Order summary
- Status tracking
- Cancel order

### Delivery Tracking
- Generate tracking links
- Update delivery status
- Track deliveries

---

## Out of Scope

- Payment gateway integration
- Mobile applications
- Multi-language support
- External ERP integrations
